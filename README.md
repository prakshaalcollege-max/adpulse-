# AdPulse AI: Marketing Spend Intelligence for UAE Online Brands

AdPulse checks every dirham of ad spend against real store orders, finds the campaigns that lose money once product margin is counted, and recommends how to split next week's budget across Meta, Google, TikTok, Snapchat, YouTube and influencers.

> **Demo data is synthetic.** All brands, campaigns and customers in `02_Data/` are fictional and were generated by `03_Code/generate_data.py`. Upload your own CSVs on the **Data & Method** page to run AdPulse on real numbers.

## Run it

**Streamlit Community Cloud**
1. Upload this whole folder to a new GitHub repository (keep the structure; `requirements.txt` must be at the top level).
2. Go to share.streamlit.io → **Create app** → deploy from GitHub.
3. Pick the repository and branch, and set **Main file path** to `03_Code/app.py`.
4. Click **Deploy**.

**Locally**
```bash
pip install -r requirements.txt
streamlit run 03_Code/app.py
```

**Reproduce the data and every result in the report**
```bash
python 03_Code/generate_data.py   # recreates 02_Data/*.csv (fixed seed)
python 03_Code/analysis.py        # recreates 04_Results/*.csv and *.png
```

## App pages

| Page | What it does |
|---|---|
| Command Centre | Claimed vs verified revenue, money leaks, recommended cuts and increases |
| Truth Check | How much each platform over-claims |
| Profit Predictor | Random Forest: will this campaign make money next week? |
| Budget Optimiser | Diminishing-returns curves and the best split of a fixed budget |
| Customer Value | K-means segments and LTV : CAC by channel |
| Scenario Lab | What if budget, ad costs or demand change? |
| Business Case | AdPulse pricing, break-even and 36-month projection |
| Data & Method | Upload your own data, templates, methodology |

## Headline results (synthetic demo data)

- Platforms claimed AED 28.18M of revenue; stores recorded AED 20.23M (39% over-claim).
- 49% of ad spend went into campaign-weeks that lost money after product margin.
- Random Forest: 85.0% accuracy, ROC AUC 0.933 on an unseen Oct-Dec hold-out (naive baseline 63.9%).
- Re-splitting the same budget: +8.4% revenue, about AED 797k a year of extra gross profit across 6 brands.
- LTV : CAC ranges from 2.71x (Google Search) to 0.49x (TikTok).
